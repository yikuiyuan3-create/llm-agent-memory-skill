本 Skill 对 DeepSeek 初稿作了相应收敛：保留有来源的结论，将建议标为建议，将绝对化说法改为条件性判断。合规、访问控制、数据删除与审计要求是落地时的工程约束，不冒充作者验证的算法结论。
